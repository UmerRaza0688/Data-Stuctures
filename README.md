# Data Structures & Algorithms

A collection of Data Structures and Algorithms implementations in **C++** and **Python**, along with **Jupyter notebooks** covering theory, visualizations, and problem walkthroughs. This repo was built as a study/practice reference while working through core DSA concepts.

## Description

This repository contains hands-on implementations of classic data structures and algorithms — linked lists, stacks, queues, trees, heaps, graphs, sorting and searching algorithms — plus utilities for expression evaluation/conversion (infix, postfix, prefix), number system conversions, and small simulation/analysis notebooks (Monte Carlo simulation, order of growth, recursion). Most structures are implemented from scratch in both C++ and Python to compare language-level approaches to the same concept.

## Usage

**C++ files:**
```bash
g++ FileName.cpp -o output
./output
```

**Python files:**
```bash
python FileName.py
```

**Notebooks:**
```bash
jupyter notebook
```
then open the desired `.ipynb` file.
